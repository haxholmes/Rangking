# Rangking

NilaiLab adalah kalkulator nilai sekolah dengan evaluasi per pelajaran dan papan ranking lokal.

## Publikasi

Situs GitHub Pages sudah diarahkan ke branch `main` pada folder root. Setelah perubahan ini digabungkan ke `main`, GitHub Pages akan menyajikan `index.html` di:

https://haxholmes.github.io/Rangking/

## Fitur dan batasan

- Penilaian standar menghitung rata-rata dari nilai yang sudah diisi.
- Penilaian penuh mewajibkan semua pelajaran aktif diisi.
- Papan ranking disimpan di `localStorage` browser; data hanya tersedia di browser/perangkat yang sama dan tidak dibagikan antar-pengunjung.

## Menjalankan lokal

Buka `index.html` di browser modern. Aplikasi tidak membutuhkan server, proses build, atau dependensi eksternal.
